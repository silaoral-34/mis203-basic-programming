Lab 02 - Purchase Quote Calculator

This folder contains a Python script that calculates a purchase quote by taking quantities and unit prices for two items, applying a 10% tax, adding a delivery fee, and displaying a formatted summary.

## Test Run
* **Inputs:**
  * Item 1: Quantity = 2, Unit Price = 50.00 TRY
  * Item 2: Quantity = 1, Unit Price = 80.00 TRY
  * Delivery Cost: 20.00 TRY
* **Calculation:**
  * Subtotal: (2 * 50) + (1 * 80) = 180.00 TRY
  * Tax (10%): 180 * 0.10 = 18.00 TRY
  * Total: 180 + 18 + 20 = 218.00 TRY
* **Expected & Output Result:** 218.00 TRY (Verified)

## Thing Changed After Testing
After initial testing, f-string formatting (`{:.2f}`) was added to ensure all monetary outputs consistently display with exactly two decimal places.
